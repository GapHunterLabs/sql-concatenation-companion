# Privacy Policy — SQL String Concatenation Companion

**Effective date:** 2026-08-19

SQL String Concatenation Companion is a Gap Hunter Labs plugin for
IntelliJ Platform IDEs. This policy is short because the plugin's design
makes it short: there is nothing to disclose beyond what's below.

## What this plugin collects

**Nothing.** SQL String Concatenation Companion does not collect,
store, transmit, or sell any data — no source code, no file contents,
no file paths, no query text, no usage analytics, no telemetry, no
crash reports, no personally identifiable information. Your open
file's text exists only in memory for as long as the IDE is open, and
only long enough to compute each warning.

## Network access

**None.** SQL String Concatenation Companion makes zero network calls
during normal operation. Every warning shown is computed directly from
files already present on your local disk — no external service, no
telemetry endpoint, ever.

## Third parties

None. SQL String Concatenation Companion has no third-party SDKs, no
analytics libraries, no ad networks, no external dependencies that
phone home.

## Changes to this policy

If this ever changes, this file will be updated and the change will be
noted in the plugin's `CHANGELOG.md`.
